## 2. 明确不做（范围护栏，跨所有 PR）

本阶段所有 PR 都不做：

- ❌ 不重写 Vision 解析、AI provider 路由、缓存、重试与熔断；
- ❌ 不改 DedupEngine 成熟去重逻辑；
- ❌ 不改 confirm 事务、镜像校验、决策 27 的双层语义、`snapshot_meta.is_current` 权威源；

- ❌ 不破坏现有快照数据、不直接 SQL 注入 0716 基金数据；
- ❌ 不重命名 / 重构 review 报告里不在范围内的公共 API；
- ❌ 不引入新依赖（不升级 React / Vite / Zustand / axios / recharts 等版本）。

**例外**：修复过程中如必须触碰成熟服务（比如 PR 1 的 StateShell 内部引用 cumulativeStore 字段），需要先证明根因、增加保护性测试、采用最小差异修改，并在 commit message 注明。
