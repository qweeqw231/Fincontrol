## 四、技术要点

### 4.1 启动页（SplashLoader）

**白底**（用户明确指定）：

```css
.splash {
  position: fixed; inset: 0;
  background: #ffffff;   /* 白底 */
  display: flex; flex-direction: column; align-items: center; justify-content: center;
  z-index: 99999;
}
.splash__logo { width: 240px; height: auto; }
.splash__title { color: #0a59f7; font-size: 16px; margin-top: 24px; font-weight: 500; }
.splash__sub { color: #8c8c8c; font-size: 13px; margin-top: 8px; }
.splash--hide { opacity: 0; pointer-events: none; transition: opacity 200ms ease; }
```

**接入点**：`src/main.jsx` 在 `ReactDOM.createRoot(...).render(...)` 之前执行：

```js
// 1) 渲染 splash 占位
const splash = document.createElement('div');
splash.className = 'splash';
splash.id = 'splash-loader';
splash.innerHTML = `
  <img class="splash__logo" src="/brand/logo_animation.gif" alt="FinControl 加载中" />
  <div class="splash__title">FinControl 加载中…</div>
  <div class="splash__sub">个人资产配置控制系统</div>
`;
document.body.appendChild(splash);

// 2) 启动 React
ReactDOM.createRoot(document.getElementById('root')).render(<App/>);

// 3) React 接管后，max 1.5s 卸载 splash
setTimeout(() => {
  splash.classList.add('splash--hide');
  setTimeout(() => splash.remove(), 250);
}, 600);
```

> Splash 由纯 HTML 注入，不依赖 React mount 时间，确保 dev server 启动后第一时间显示。

### 4.2 后端 SystemController

```java
@RestController
@RequestMapping("/api/system")
public class SystemController {

  @Value("${fincontrol.system.shutdown.enabled:true}")
  private boolean shutdownEnabled;

  @Value("${fincontrol.system.shutdown.grace-millis:800}")
  private long graceMillis;

  @Autowired private ApplicationContext ctx;

  @PostMapping("/shutdown")
  public ApiResponse<Map<String, Object>> shutdown() {
    if (!shutdownEnabled) {
      return ApiResponse.error(403, "shutdown endpoint disabled");
    }
    // 异步触发 exit；同步先返回响应
    new Thread(() -> {
      try { Thread.sleep(graceMillis); } catch (InterruptedException ignored) {}
      SpringApplication.exit(ctx, () -> 0);
    }, "fincontrol-shutdown").start();
    return ApiResponse.success(Map.of("shuttingDown", true, "graceMillis", graceMillis));
  }
}
```

**安全护栏**：
- `enabled=false` 时返回 403（防误开 + 留远程禁用开关）；
- grace period 800ms 让 in-flight 请求完成；
- 前端 5 秒内二次点击防误关。

### 4.3 HomePage 关闭按钮

**位置**：`HomePage` 顶部 Header 右上角（与 hero card 同行右侧），36×36 圆形按钮。

**交互（防误点）**：
1. 第 1 次点击 → 按钮变红色 + toast「再点一次确认关闭（5 秒倒计时）」；
2. 5 秒内第 2 次点击 → 调 `POST /api/system/shutdown` → 按钮 disabled + 显示「服务关闭中…」；
3. 后端 800ms 内退出 → Vite 失去 backend → 浏览器显示"服务已关闭，请重新启动"。

**Hover Tooltip**：用原生 `title` 属性，简洁不引入新依赖。

```jsx

  onClick={handleShutdownClick}
  disabled={shutdownState !== 'idle'}

  aria-label="关闭服务"
>
  <svg viewBox="0 0 24 24" width="20" height="20" fill="currentColor">
    <path d="M13 3h-2v10h2V3zm4.83 2.17l-1.42 1.42C17.99 7.86 19 9.81 19 12c0 3.87-3.13 7-7 7s-7-3.13-7-7c0-2.19 1.01-4.14 2.58-5.42L6.16 5.17C4.23 6.82 3 9.26 3 12c0 4.97 4.03 9 9 9s9-4.03 9-9c0-2.74-1.23-5.18-3.17-6.83z"/>

{shutdownState === 'confirming' && (
  <div className="shutdown-toast">
    再点一次确认关闭（5 秒倒计时）

{shutdownState === 'shutting-down' && (

  </div>
)}
```

### 4.5 launch-fincontrol.ps1 主流程

```powershell
# 1) 检查 MySQL，没起就启动
$mysqlService = Get-Service -Name 'MySQL80' -ErrorAction SilentlyContinue
if ($mysqlService.Status -ne 'Running') {
  Start-Service -Name 'MySQL80'
  Start-Sleep -Seconds 3
}

# 2) 启动后端（统一走决策 24 脚本）
& "$PSScriptRoot\..\1b\restart-backend.ps1"

# 3) 等后端 health = UP
$ready = $false
for ($i = 0; $i -lt 30; $i++) {
  try {
    $r = Invoke-WebRequest -Uri 'http://localhost:8080/actuator/health' -UseBasicParsing -TimeoutSec 2
    if ($r.StatusCode -eq 200 -and ($r.Content | ConvertFrom-Json).status -eq 'UP') {
      $ready = $true; break
    }
  } catch { Start-Sleep -Seconds 1 }
}
if (-not $ready) { Write-Error 'Backend failed to become ready'; exit 1 }

# 4) 后台启动 Vite dev server，记录 PID
$env:Path += ';C:\Program Files\nodejs'
$proc = Start-Process -FilePath 'npm.cmd' -ArgumentList 'run','dev','--prefix','fincontrol-frontend' `
              -WindowStyle Hidden -PassThru
$proc.Id | Set-Content -Path "$PSScriptRoot\..\..\.tmp\vite.pid" -Encoding UTF8

# 5) 等 5 秒后开 Chrome
Start-Sleep -Seconds 5
Start-Process 'chrome.exe' 'http://localhost:5173/'
```

### 4.6 stop-fincontrol.ps1 主流程

```powershell
# 1) 停 Vite
if (Test-Path "$PSScriptRoot\..\..\.tmp\vite.pid") {
  $vitePid = Get-Content "$PSScriptRoot\..\..\.tmp\vite.pid"
  Stop-Process -Id $vitePid -ErrorAction SilentlyContinue -Force
  Remove-Item "$PSScriptRoot\..\..\.tmp\vite.pid"
}

# 2) 停 Spring Boot（走 stop-backend.ps1）
& "$PSScriptRoot\..\1b\stop-backend.ps1"

# 3) 询问 MySQL
$ans = Read-Host "Close MySQL too? (y/N)"
if ($ans -eq 'y') { Stop-Service -Name 'MySQL80' -Force }
```

### 4.7 stop-backend.ps1（新建）

```powershell
# 通过 actuator health 拿 process ID 找 java 进程
$javaProcs = Get-Process -Name java -ErrorAction SilentlyContinue | `
  Where-Object { $_.MainModule.FileName -like '*fincontrol-backend*' -or `
                 $_.CommandLine -like '*fincontrol-backend*' }
foreach ($p in $javaProcs) {
  try { Stop-Process -Id $p.Id -Force } catch { }
}

# 等 5 秒
Start-Sleep -Seconds 5

# 验证
$stillRunning = Get-Process -Name java -ErrorAction SilentlyContinue | `
  Where-Object { $_.CommandLine -like '*fincontrol-backend*' }
if ($stillRunning) {
  Write-Warning "Backend still running: $($stillRunning.Id -join ',')"
} else {
  Write-Host "Backend stopped."
}
```
