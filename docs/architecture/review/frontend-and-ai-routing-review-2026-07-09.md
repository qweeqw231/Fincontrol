## 6. 最关键的 5 类风险

1. **大类确认面板的"误操作即污染"风险（问题 2.2.1.1、2.2.2.1、2.2.2.2）**。提交前无预览、提交后无撤销、单只基金无法编辑——三个缺失叠加，导致一旦误操作，数据修复成本极高。Phase 1 必须补齐。

2. **余额类未纳入下拉选择器（问题 2.2.4.3）**。第一轮评审确定 asset_raw.category 增加"余额类"，但 5.6.4 的下拉列表仍只有六大类。这是"评审结果未传递到 UI 设计"的典型遗漏，会导致余额宝/余额无法正确分类。

3. **AI 顾问的回路切换实现未定义（问题 3.2.1、3.2.2）**。"系统 Prompt 中途切换"在 DeepSeek API 中不原生支持，需要每次调用都重新组装 messages。这个实现细节缺失会导致 Phase 1 编码时临时拼凑。

4. **意图分类器边界歧义（问题 3.1.1-3.1.4）**。"投资决策咨询"采用举例式定义，缺乏正反例，会导致分类不稳定（同一问题不同时间分类不同）。Phase 1 启动前需补充 few-shot 示例。

5. **跨页面状态共享方案缺失（问题 1.5.1、1.5.2）**。/data 上传截图后，/correction 默认值是否更新？/config 修改后首页是否更新？无全局状态管理会导致数据不一致或需要每次手动刷新。
