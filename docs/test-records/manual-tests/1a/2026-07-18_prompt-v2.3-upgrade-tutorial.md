# 1a.8.8 prompt_versions v2.3 升级教程（无 GUI 客户端方案）

**目标**：把本地 MySQL `fincontrol` 库的 `prompt_versions` 表里 `screenshot_parser` 从 v2.2 升级到 v2.3。
**v2.3 内容**：7 canonical 类别名 + 别名映射（QDII → 海外权益类 等），详见 [decisions.md §决策 8](../../phase-0/decisions.md)。

**前置**：你的本机已找到 `mysql.exe` 在 `C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe`，**无需安装任何 GUI**。

---

## 一键教程（推荐）：双击 bat 自动跑

### Step 1：在 Windows 资源管理器中打开 `.tmp/` 目录

```
C:\Users\lbc19\Desktop\Fincontrol\.tmp\
```

你应该看到 3 个文件：
- `do-commit-push.bat`（1a.8.8 已 push，无需重跑）
- `prompt-v2.3.sql`（SQL 文本，**不要双击**）
- `run-prompt-v2.3.bat`（**双击这个**）

### Step 2：双击 `run-prompt-v2.3.bat`

会弹出黑色 cmd 窗口，提示：
```
=== 1a.8.8 prompt_versions v2.3 升级脚本 ===
=== 时间：2026/07/18 21:33 ===
=== MySQL：C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe ===
=== SQL：C:\...\prompt-v2.3.sql ===
=== 日志：C:\...\prompt-v2.3-result.log ===

请输入 MySQL root 密码（无密码直接回车）：
```

输入密码（无密码直接按 Enter），然后会看到：

```
id  prompt_name        version  change_reason                            created_at
--  ----                 --------  --------                                ----
 2  screenshot_parser  v2.2      1a.8.7 双字段 + total_asset visible  ...
```

接着是 `INSERT` 成功提示（`Query OK, 1 row affected` 或 `0 rows affected` 如果已存在）。

最后是 `SELECT` 验证：

```
id  prompt_name        version  change_reason                            created_at
--  ----                 --------  --------                                ----
 4  screenshot_parser  v2.3      1a.8.8 类别归一化 + 双向 cache + 多用户预留  2026-07-18 21:33:xx
```

如果看到 **id=4, version=v2.3** 那行，说明升级成功 ✅。

### Step 3：查看完整日志

打开 `C:\Users\lbc19\Desktop\Fincontrol\.tmp\prompt-v2.3-result.log`，里面有完整 SQL 执行回显。

### Step 4（必须）：应用 v2.3 生效

`prompt_versions` 表里的内容是**缓存式加载**（启动时 warm up）。升级完 v2.3 后：

```
方式 A（推荐）：重启后端
  1. Ctrl+C 关掉当前的 mvn spring-boot:run
  2. 重新跑 cd fincontrol-backend && mvn spring-boot:run

方式 B（应急）：后端启动时会自动 warm-up，新启动即可生效
```

> v2.3 生效后，下次截图解析会输出 canonical 类别名（如 "QDII" → "海外权益类"）。

## 备选教程（手动复制粘贴）

如果 bat 双击有问题，可以用 cmd 手动：

```cmd
:: 1. 打开 cmd，进入 .tmp 目录
cd C:\Users\lbc19\Desktop\Fincontrol\.tmp

:: 2. 用 mysql.exe 直接喂 SQL 文件
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p fincontrol < prompt-v2.3.sql
:: 输入密码回车

:: 3. 验证 v2.3
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p fincontrol -e "SELECT id, version, change_reason FROM prompt_versions WHERE prompt_name='screenshot_parser' AND version='v2.3';"
:: 应该返回 1 行 id=4 version=v2.3
```

## 回滚方案（如果 v2.3 升级后 OCR 反而坏了）

```sql
-- 1. 删除 v2.3
DELETE FROM prompt_versions WHERE prompt_name = 'screenshot_parser' AND version = 'v2.3';

-- 2. 重启后端（会自动从已有版本选最新 = v2.2）
--    或者如果你之前给 v2.2 加了 fallback 标记，可以手动改 PromptLoaderService
```
