## 2. 修环形图黑框

### 2.1 根因
- Recharts `<Pie>` 默认 `activeShape` 用 SVG path，hover 时 fill 解析失败 → 黑色块
- 加上 SVG 里 `var(--color-cat-*)` 也不解析，Cell 的 fill 正常但 active 状态 fallback 到默认色（黑）

### 2.2 修复
- `SixCategoriesPie.jsx` 加 `activeShape` 自定义（用 `<Sector>` + 白色描边 + 外扩 6px）
- 补 `import { Sector }` from 'recharts'

### 2.3 验证
- 浏览器刷新后，hover 扇区看到高亮（白边 + 外扩 6px），不再黑框
