### 1.3 数据回填（手动跑）

为启用 R5 锚点计算，需要给现有 fund_category_map 数据回填 last_seen_snapshot_date：

```sql
UPDATE fund_category_map fcm
JOIN (
    SELECT fund_name, MAX(snapshot_date) AS last_seen
    FROM asset_raw
    WHERE user_id = 1 AND is_latest = true
    GROUP BY fund_name
) ar ON fcm.fund_name = ar.fund_name
SET fcm.last_seen_snapshot_date = ar.last_seen
WHERE fcm.user_id = 1 AND fcm.last_seen_snapshot_date IS NULL;
```

**注意**：此回填**未跑**（因为 SQL 迁移中断了），所以 R5 锚点当前为 NULL。下次用户 confirm 时会从 anchorDate=null 触发 R5 推进逻辑。

## 六、剩余风险

1. **R5 数据回填未跑**：下次 confirm 时 anchorDate=null → 立即进入 forward inference（因为 anchorDate=null 被认为 isAnchorUpdate=true）→ 当前快照所有 fund 都被设置 last_seen_snapshot_date = currentSnapshotDate → **首次回填完成**
2. **fund_name 字符串篡改 bug**（鹏华→债票）：match API 永远返回 unmatched（不在 R5 范围，pr6c 修复）
3. **前端模块 B 未做**：用户当前实际看不到 R5 效果（preview modal UI 缺失），但后端准备就绪
